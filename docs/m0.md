# M0. Дамп Xbox и контрольные сборки

## Игровые данные

- Для проверки использован локальный ISO US Xbox объёмом 7 825 162 240 байт.
- Штатный импортёр проверил раздел XDVDFS по смещению 405 798 912 и извлёк 412 файлов в `private/game/`. Локальная проверка подтвердила структуру каталога и SHA-256 `default.xbe` для US Xbox.
- Checkout PC-порта использует символическую ссылку на `private/game/`. ISO, извлечённые ресурсы и результаты анализа хранятся в игнорируемых каталогах.

## Эталон на Mac

Закреплены TimeSplitters: Future Perfect PC `v0.5.0` (`be641d9db1f12aa757213388738a24829d5fc083`) и его runtime `d90c92988a9f99d0580d2ca3f7efd6ec3a7b7845`. Для macOS 15.5 выбран поддерживаемый исходниками путь OpenGL. Он позволяет проверить генерацию и работу игрового кода на ARM64. Проверка общего Vulkan RHI остаётся отдельной.

Команды из корня проекта при уже импортированном дампе и подготовленной ссылке:

```sh
python3 tools/check_game_dump.py private/game
cd external/tsfp-pc
python3 tools/build/build-native-mac.py --setup --generate --without-textures --renderer gl
.venv/bin/python tools/testing/test-native-mac.py --seconds 30 --capture
```

Штатный генератор завершил все четыре стадии. В отчёте 15 838 транслированных функций из 15 863 и 728 записей о неподдержанных инструкциях. Их достижимость в игре требует проверки. Линковку OpenGL исправил [патч вызова SSAO](../patches/legacy-gl-ambient-occlusion.patch). После этого контрольная сборка загрузила оригинальный XBE, инициализировала графику и показала заставку TimeSplitters: Future Perfect. Прогон с изолированными сохранениями завершён по лимиту в 30 секунд. Меню и миссия в этом прогоне не проверялись.

Журнал компиляции находится в `external/tsfp-pc/logs/quest3-m0-build.log`, итог повторной линковки в `quest3-m0-link.log`, отчёт запуска в `native-boot-summary.json`. Захваты заставки находятся в `external/tsfp-pc/private/captures/native-mac/`.

## Диагностика Quest

Собран `build/openxr-diagnostic/hello-xr-vulkan-arm64-debug.apk` на основе Khronos OpenXR SDK Source `release-1.1.49` (`47c4761d05b27f884247480ac3fb8a6657907325`). Подпись APK проверена через `apksigner`. `aapt2` подтвердил пакет `org.khronos.openxr.hello_xr.vulkan` и единственный ABI `arm64-v8a`. В APK входят диагностическая сцена и загрузчик OpenXR.

Локальный [патч](../patches/hello-xr-ndk27.patch) приводит параметры примера к SDK 35, NDK 27, Gradle 8.12 и AGP 8.9.2 из соседнего проекта ReChan. Для NDK 27 пример использует `ALooper_pollOnce`. Сборка выполнена после разрешения зависимостей Gradle.

```sh
root="$PWD"
rechan="$root/../rechan-quest/.toolchain"
xr="$root/external/openxr-sdk-source"
# Один раз в чистом checkout release-1.1.49.
git -C "$xr" apply "$root/patches/hello-xr-ndk27.patch"
export JAVA_HOME="$rechan/jdk/Contents/Home"
export ANDROID_HOME="$rechan/sdk"
export ANDROID_USER_HOME="$root/build/openxr-diagnostic/android-user"
export GRADLE_USER_HOME="$rechan/gradle"
export PATH="$ANDROID_HOME/ndk/27.0.12077973/shader-tools/darwin-x86_64:$PATH"
mkdir -p "$ANDROID_USER_HOME"
gradle=$(find "$GRADLE_USER_HOME/wrapper/dists/gradle-8.12-bin" -path '*/bin/gradle' -print -quit)
sample="$xr/src/tests/hello_xr"
"$gradle" -p "$sample" --no-daemon assembleVulkanDebug
cp "$sample/build/outputs/apk/vulkan/debug/hello_xr-Vulkan-debug.apk" \
  "$root/build/openxr-diagnostic/hello-xr-vulkan-arm64-debug.apk"
```

ADB установил APK на Quest 3 с Android 14. После активации Touch пользователь увидел разноцветные кубы и модели обоих контроллеров. Журнал подтвердил Vulkan swapchain, состояние OpenXR `FOCUSED` и профили Touch для обеих рук. Между отметками `BeginFrame (500)` и `BeginFrame (2000)` прошло 16,67 с, около 90 вызовов начала кадра в секунду в этой диагностической сцене. Пропуски кадров композитора отдельно не измерялись.

```sh
"$ANDROID_HOME/platform-tools/adb" install -r build/openxr-diagnostic/hello-xr-vulkan-arm64-debug.apk
```

## Первые проверки Android ARM64

- На Mac прошли 13 тестов upstream из `test_guest_map_layout.py` и `test_host_pages.py`. Две проверки, `guest-map-layout` и `host-pages`, собраны NDK 27 как исполняемые файлы Android API 29. Обе успешно завершились на Quest 3 через ADB. Размер страницы на проверенном шлеме — 4096 байт.
- Первый блок сгенерированного кода игры, `recomp_0000.c`, скомпилирован NDK 27 с `-O0 -fPIC` и каталогами заголовков штатной сборки. На выходе объект ELF64 AArch64, `build/android-contracts/recomp_0000.o`. Компоновка runtime и полный запуск ещё впереди.
- CMake игрового runtime выбирает MMIO для Apple ARM64 или Linux x64. Для Android нужна поддержка ARM64-контекста сигналов. Общий декодер инструкций находится в `src/native/arm64_access.h`.
- Vulkan-обвязка в `src/native/vulkan_backend.cmake` выбирает DXC для macOS и Linux. Для Android предстоит проверить сборку или замену компилятора динамических шейдеров.
