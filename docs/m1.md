# M1. Запуск игры на Android ARM64

Проект `android/` собирает сгенерированный код игры, Xbox runtime и SDL3 в одну библиотеку `libtsfp_boot.so`. Android Activity запускает её на потоке SDL. Vulkan-вывод игры входит в M2. При первом запросе графического устройства M1 записывает его параметры в журнал.

## Сборка и установка

Из корня проекта, после генерации C по [M0](m0.md), выполнить `android/build.sh`. Скрипт использует NDK 27, Android SDK 35 и JDK из соседнего проекта ReChan, если переменные `ANDROID_HOME` и `JAVA_HOME` не заданы. Он применяет патчи к закреплённым рабочим копиям PC-порта и Xbox runtime, сохраняет библиотеку с символами и подписывает локальный debug APK.

```sh
android/build.sh
adb install -r build/android/timesplitters-m1-debug.apk
```

Импорт для чистой установки. Команда разворачивает подготовленный дамп в промежуточную папку, затем переименовывает её. При наличии `files/game` используйте уже импортированные данные.

```sh
adb shell run-as org.tsfp.quest mkdir -p files
adb shell run-as org.tsfp.quest test ! -e files/game
incoming=$(adb shell run-as org.tsfp.quest mktemp -d files/game.incoming.XXXXXX)
COPYFILE_DISABLE=1 tar -cf - -C private/game default.xbe pak xmv |
  adb shell -T run-as org.tsfp.quest tar -xf - -C "$incoming"
adb shell run-as org.tsfp.quest sha256sum "$incoming/default.xbe"
adb shell run-as org.tsfp.quest mv "$incoming" files/game
adb shell am start -W -n org.tsfp.quest/.MainActivity
adb shell run-as org.tsfp.quest cat files/boot.log
```

Ожидаемый SHA-256 `default.xbe` равен `3cfd001a84fc3e08175d6c4b2e42ebf49577a089b5d0bd87ac724f61a41816bc`. Игровые данные хранятся в приватной папке приложения. При обновлении APK с тем же ключом папка сохраняется.

## Проверки

- Тест MMIO `tsfp_mmio_test` на Quest 3 подтвердил восстановление после записей в защищённые регистры, подтверждение прерывания NV2A и сброс AC97.
- Пакет устанавливается через ADB. В приватную папку импортированы 410 файлов, SHA-256 `default.xbe` проверен на устройстве.
- На Android проверка прав страниц использует текстовый `/proc/self/maps`. Журнал SELinux показал отказ в Linux ioctl `PROCMAP_QUERY` внутри процесса APK. Текстовый путь сохраняет проверку актуальных границ и прав доступа.
- Приложение задаёт приватный кеш как `TMPDIR` для временных файлов, которые нужны при размещении памяти гостя. [Исходники Bionic](https://android.googlesource.com/platform/bionic/+/master/libc/bionic/tmpfile.cpp)
- На Quest код Xbox загрузил XBE, инициализировал память и таблицу вызовов ядра, вошёл в перекомпилированную точку входа и запросил устройство D3D8 640×480. Журнал сохранился в `logs/m1-quest-boot.log`. Кадр игры на Quest ещё не выводится.
