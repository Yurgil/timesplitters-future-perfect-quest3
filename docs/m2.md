# M2. Vulkan в окне Android

Android-окно доступно через `org.tsfp.quest/.MainActivity` в текущем APK и использует приватные файлы игры, импортированные в M1. Иконка приложения запускает виртуальный экран OpenXR. [Сборка и управление](m3.md)

## Сборка

Из корня проекта после подготовки runtime и сборки диагностического APK по M0:

```sh
git -C external/tsfp-pc/external/ts3FPrecomp submodule update --init \
  third_party/Vulkan-Headers third_party/volk third_party/VulkanMemoryAllocator
android/build.sh
adb install -r build/android/timesplitters-xr-debug.apk
adb shell am start -W -n org.tsfp.quest/.MainActivity
```

Сборка использует Shaderc из NDK 27 и общий Xbox/Vulkan-бэкенд. Shaderc переводит HLSL в SPIR-V на шлеме. Привязки буферов, текстур и сэмплеров совпадают с теми, которые ожидает рендерер. Адаптер переносит HLSL-семантики в имена SPIR-V для существующего механизма связывания шейдеров и сохраняет отдельный кеш для Shaderc. [Документация Shaderc для Android](https://github.com/google/shaderc/blob/main/libshaderc/README.md)

SDL инициализирует видео на потоке игры до запуска гостевого кода. Когда Xbox просит создать устройство D3D8, приложение создаёт Vulkan-окно и поверхность через SDL. В игровом журнале на Quest 3 подтверждены Adreno 740, Vulkan 1.3, режим представления MAILBOX и формат глубины D24S8.

## Проверки

- Пользователь подтвердил, что кадр виден в шлеме. Заставка, главное меню и брифинг `2401 — Time to Split` отдельно проверены чтением буфера игры на Quest 3.
- Прогон со сценарием ввода создал профиль. После остановки процесса профиль `Player 1` появился в списке и загрузился. Через него пройдены брифинг и выбор сложности `Normal`. Кадры из игрового буфера подтвердили сцену крушения и переход к виду от первого лица с оружием и HUD.
- SDL открыл аудиовыход. DirectSound отправлял буферы, а Android AudioFlinger зарегистрировал поток процесса игры. Физическое управление и слышимый звук требуют проверки в шлеме. В этой сборке XMV-ролики пропускаются, поскольку FFmpeg для Android ещё не подключён.
- Проверочный HLSL-шейдер сохранил семантики `TEXCOORD2`, `COLOR0` и `SV_TARGET0` после преобразования. `spirv-val` подтвердил полученный модуль Vulkan 1.1.

Для захвата кадров запустить Activity с `--ez capture_frames true`. Кадры ротируются в `cache/frame000.bmp` и `cache/frame001.bmp`. Чтобы повторить автоматизированный ввод, перед запуском поместить строку формата `13000:start,16000:a` в `cache/input-sequence.txt` через `run-as org.tsfp.quest`. Этот файл доступен только из приватной папки приложения. Для обычного запуска удалить его.

```sh
adb shell am start -W -n org.tsfp.quest/.MainActivity --ez capture_frames true
adb exec-out run-as org.tsfp.quest cat cache/frame000.bmp > frame.bmp
adb exec-out run-as org.tsfp.quest cat files/boot.log > boot.log
```
